# Logic Analyzer
<img width="539" height="592" alt="image" src="https://github.com/user-attachments/assets/bace24c3-5209-468e-9407-9bfd8c95b0b4" />

Навчальний проєкт для ESP32-S3 на Arduino framework і PlatformIO. Прошивка рахує натискання кнопки на GPIO 16 за допомогою переривання та виводить поточний лічильник у серійний монітор.

## Що робить проєкт

Після запуску контролер налаштовує GPIO 16 як вхід із внутрішнім підтягуванням `INPUT_PULLUP`, запускає серійний порт на швидкості 115200 бод і прив'язує до входу обробник переривання на спадний фронт (`FALLING`). Коли рівень на вході переходить із `HIGH` у `LOW`, обробник збільшує лічильник. Головний цикл помічає зміну лічильника та виводить повідомлення, наприклад `Button Pressed! Count: 1`.

У поточній версії немає програмного усунення брязкоту контактів, тому одне фізичне натискання може бути пораховане кілька разів. Якщо вхід залишається непідключеним або дроти довгі, перешкоди також можуть спричиняти хибні спрацювання.

## Які задачі виконує та чого навчає

- Налаштовує цифровий вхід ESP32-S3 із `INPUT_PULLUP`.
- Демонструє переривання GPIO та реакцію на спадний фронт сигналу.
- Показує, як обробник переривання змінює `volatile`-лічильник, а головний цикл читає його.
- Виводить значення лічильника в серійний порт для спостереження.

## Обладнання та підключення

- ESP32-S3 DevKitM-1 або сумісна плата.
- Кнопка між GPIO 16 і GND. Зовнішній підтягувальний резистор не потрібен: використовується внутрішній `INPUT_PULLUP`.
- Спільний GND між кнопкою та платою.

Коли кнопка відпущена, вхід має читатися як `HIGH`; під час натискання він замикається на GND і читається як `LOW`. Перевірте розпіновку конкретної плати та переконайтеся, що GPIO 16 не використовується іншою периферією. Для надійного підрахунку реальної кнопки додайте усунення брязкоту контактів або апаратний RC-фільтр.

## Збірка, завантаження та моніторинг

Потрібні [Visual Studio Code](https://code.visualstudio.com/) із розширенням [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) або PlatformIO Core. Під'єднайте плату USB-кабелем із передаванням даних і виконайте:

```sh
pio run
pio run --target upload
pio device monitor
```

Серійний монітор налаштований на 115200 бод. Якщо PlatformIO не визначає порт автоматично, задайте `upload_port` та/або `monitor_port` у `platformio.ini`.

## Налаштування PlatformIO

`platformio.ini` задає платформу Espressif32 `~6.8.1`, плату `esp32-s3-devkitm-1` і Arduino framework. Параметри пам'яті налаштовані на 16 MB flash, 8 MB PSRAM і режим `qio_opi`. Переконайтеся, що ваша плата має таку конфігурацію, і за потреби змініть параметри.
